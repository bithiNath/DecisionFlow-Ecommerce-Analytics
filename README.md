# DecisionFlow-Ecommerce-Analytics

DecisionFlow is a multi-store e-commerce business operating across different regions. Management wants to improve revenue, profitability, inventory availability, customer retention, operational efficiency, payment collection, and sales target achievement through data-driven decision making.

## objective:

The objective of this project is to analyze the company's transactional and operational data using SQL, identify key business problems and their root causes, quantify their business impact, and provide actionable recommendations. The project will later be extended into a BI dashboard and an automated decision-support system.
